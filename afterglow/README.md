# Afterglow

Territory-control game for electronic-music nightlife. Check into shows, capture venues for your
crew, and watch the map of NYC turn your colors. "Untappd for raving" meets a map-based control game.

## Run the prototype
Open `prototype/index.html` in a browser, or `npx serve prototype`. Allow location access to test GPS.

## What's here
- `prototype/index.html` — working clickable prototype (Leaflet map, real GPS geofence, XP, territory)
- `data/` — verified venue + lineup data, crew definitions
- `docs/` — product, data sources, verification, design, roadmap
